# GCSE Boss Website

Marketing site for [gcseboss.com](https://gcseboss.com).

## Adding blog posts

1. Create a new HTML file in `blog/posts/` (copy `welcome-to-gcse-boss.html` as a template).
2. Add a card to `blog/index.html` linking to the new post.
3. Optionally add a clean URL in `_redirects`, e.g. `/blog/my-post-slug  /blog/posts/my-post-slug.html  200`.

Push to `main` — Cloudflare deploys automatically.
